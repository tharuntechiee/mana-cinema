MANA CINEMA - movie pictures

Every movie already shows drawn hero artwork. To use a real picture instead:

1. Save the picture in this folder:
     posters:  images/posters/   (tall, about 600 x 900, ratio 2:3)
     OG cover: images/cover/     (wide, about 1920 x 1080)

2. Open js/data.js and add the file name to that movie, for example:
     { id: 10, ..., image: "images/posters/they-call-him-og.jpg", coverImage: "images/cover/og-cover.jpg", ... }
     { id: 1,  ..., image: "images/posters/kalki-rising.jpg", ... }

3. Reload the website (Ctrl + F5).

Only use pictures you have the right to use: your own photos, official press-kit images,
or free-licence images (for example from commons.wikimedia.org, with the credit it asks for).
