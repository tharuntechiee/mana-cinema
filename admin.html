            About this portal
            
            
              
              
            • This is a front-end demo. Films, collections and ratings are saved in this browser's storage, not on a server.
              • 
              
            • The sign-in only keeps casual visitors out. It isn't real security: anyone can read the password in the page's code.
              • 
              
            • Audience ratings exist only in the browser where they were posted, so other visitors and devices don't see them.
              • 
              
            • To share data between browsers, use backup and restore, or run the site on its server (npm start).
              • 
              
            • Collections are trade estimates (mostly Sacnilk, India net). Keep each film's sources and as-of date up to date.
              • 
              
            • Films in the language lists often have totals only: no day-wise figures, story line or critics. Needs attention doesn't flag those gaps; it only asks for day-wise figures on releases from the last 60 days.
              • 
            
            
            
              
              
            • Films, collections, ratings, audience reviews and messages are saved in the server's SQLite database, so every visitor and device sees the same data.
              • 
              
            • The server checks the admin password (ADMIN_PASSWORD in its .env file). A sign-in lasts 12 hours.
              • 
              
            • IMDb ratings and principal cast and crew come from IMDb's official datasets, for personal and non-commercial use. The site credits IMDb wherever they appear.
              • 
              
            • With a TMDB key, cast and crew come from TMDB instead: every actor and the whole crew. With a YouTube key, the sync finds each film's trailer and keeps its views up to date.
              • 
              
            • An IMDb rating you type in Ratings is replaced at the next daily IMDb refresh, for films with an IMDb ID.
              • 
              
            • Collections are trade estimates (mostly Sacnilk, India net). Keep each film's sources and as-of date up to date.
              • 
              
            • Films in the language lists often have totals only: no day-wise figures, story line or critics. Needs attention doesn't flag those gaps; it only asks for day-wise figures on releases from the last 60 days.
